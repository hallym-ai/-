# COEX X HANLLYM AI Resizing

이미지 또는 PDF 시안을 선택한 규격에 맞춰 생성하고, 결과를 PNG·JPG·PDF로 저장하거나 텍스트로 수정을 요청하는 웹 애플리케이션입니다.

## 주요 기능

- PDF, PNG, JPG 업로드 및 PDF 페이지 선택
- 6가지 규격 중 필요한 크기만 생성
- 시안별 선택 다운로드 및 여러 시안 ZIP 다운로드
- 선택 시안에 대한 텍스트 수정 요청
- 출력 규격을 유지하는 선택적 선명화

## 로컬 실행

Node.js 22.13 이상과 npm이 필요합니다. 저장소의 루트에서 다음 명령을 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. 이 프로젝트는 Vinext와 Cloudflare Workers 환경을 사용하며, 일반적인 정적 호스팅만으로는 이미지 생성 API가 동작하지 않습니다.

이미지 생성에는 OpenAI API 키가 필요합니다. 로컬 Worker 개발 환경에서 프로젝트 루트의 `.dev.vars`에 `OPENAI_API_KEY`를 설정하거나, 배포 환경의 서버 측 비밀 설정에 같은 이름으로 등록하세요. `.dev.vars`와 환경 파일은 Git에서 제외됩니다. 키를 프런트엔드 코드, 저장소, 브라우저에 넣지 마세요. 키 없이도 화면을 볼 수 있지만 생성 요청은 사용할 수 없습니다.

## 인증과 공개 배포

현재 생성 API는 OpenAI Sites의 인증된 사용자 헤더와 서버 측 `OPENAI_API_KEY`에 의존합니다. 이 저장소에는 기존 사이트의 프로젝트 ID나 비밀 설정이 포함되어 있지 않습니다. 다른 호스팅 환경에서는 신뢰할 수 있는 인증 계층과 비밀 저장소를 별도로 구성해야 합니다. 클라이언트가 임의로 보낸 인증 헤더를 신뢰하면 안 됩니다.

공개 서비스로 운영하려면 이용자 인증, 사용량 제한 및 비용 관리 등을 운영 환경에 맞게 구성하세요. 업로드한 시안은 이미지 생성·수정 요청 시 OpenAI API로 전송되며 API 이용 요금이 발생할 수 있습니다.

## 구성

- `app/`: 화면 및 이미지 생성 API
- `lib/files.ts`, `lib/sharpen.ts`: 파일 읽기 및 저장
- `public/`: 이미지와 PDF 렌더링 자산
- `worker/`, `vite.config.ts`: Cloudflare Workers 및 Vinext 실행 구성
- `.openai/hosting.json`: 기존 프로젝트 ID가 제거된 빈 바인딩 설정

이미지 생성 결과는 원본의 상품, 글자, 배치를 완벽하게 보존하지 않을 수 있으므로 사용 전 확인해 주세요.
